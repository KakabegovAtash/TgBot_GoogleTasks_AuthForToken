# Google Tasks OAuth Token Generator 🌸

Утилита для удобного получения токенов авторизации Google Tasks API (`token.json`). Поддерживает два режима работы:
1. **CLI (консольный режим):** для локального использования.
2. **Web-интерфейс (FastAPI):** красивый веб-интерфейс с «милым розовым» дизайном, созданный специально для удаленной авторизации нетехнических партнеров (например, с использованием Cloudflare Tunnel).

Этот токен (`token.json`) в дальнейшем используется Telegram-ботом (`TgBot_GoogleTasks`) для синхронизации и мониторинга задач.

---

## 🛠 Возможности

- 🚀 **Быстрая локальная авторизация** через консольный скрипт `auth.py`.
- 🌸 **Милый Web-интерфейс** на FastAPI со стеклянным (Glassmorphism) эффектом, летающими сердечками и праздничным конфетти при успешном входе.
- 🔗 **Динамический Redirect URI**: Автоматически подстраивается под внешние туннели (например, Cloudflare Tunnel), преобразовывая URL в защищенный `https://`.
- 🔒 **Безопасность**: Конфиденциальные данные (`credentials.json`, `token.json`, `.env`) исключены из коммитов через `.gitignore`.

---

## 📂 Структура проекта

- `app.py` — веб-сервер на FastAPI для удаленной авторизации.
- `auth.py` — консольный скрипт авторизации для локального ПК.
- `templates/` — HTML-шаблоны (`index.html` и `success.html`) с адаптивным дизайном и анимациями.
- `.env.example` — пример файла с переменными окружения.
- `credentials.json.example` — пример структуры конфигурации Google OAuth.

## 🚀 Быстрый старт

### 1. Подготовка окружения
Клонируйте репозиторий и установите необходимые зависимости:

```bash
git clone https://github.com/KakabegovAtash/TgBot_GoogleTasks_AuthForToken.git
cd TgBot_GoogleTasks_AuthForToken

# Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка Google Cloud Console
Для работы с Google API необходимо создать проект в [Google Cloud Console](https://console.cloud.google.com/):

1. Создайте проект (или выберите существующий).
2. В разделе **APIs & Services > Library** найдите и включите **Google Tasks API**.
3. В разделе **OAuth consent screen**:
   - Настройте экран согласия (для тестирования выберите тип **External**).
   - Обязательно добавьте тестовых пользователей (email тех, для кого будете получать токен).
   - Добавьте область действия (Scope): `https://www.googleapis.com/auth/tasks.readonly`.
4. В разделе **Credentials** нажмите **Create Credentials > OAuth client ID**:
   - Для **CLI**-версии: тип приложения **Desktop app** (Вам не потребуется настраивать Redirect URIs).
   - Для **Web**-версии: тип приложения **Web application**. Добавьте в список разрешенных Redirect URIs:
     - `http://localhost:8000/callback` (для локального тестирования)
     - `https://<ВАШ_САБДОМЕН>.trycloudflare.com/callback` (если используете Cloudflare Tunnel)
5. Скачайте JSON-файл учетных данных и сохраните его в корне проекта под именем `credentials.json`.

> [!NOTE]
> Вы можете использовать `credentials.json.example` в качестве шаблона для ручного заполнения параметров `client_id` и `client_secret`.

### 3. Настройка конфигурации

1. Скопируйте файл с переменными окружения:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и настройте ключ сессии `SESSION_SECRET_KEY` (используется для защиты сессий в FastAPI):
   ```env
   SESSION_SECRET_KEY=ваш-секретный-ключ-для-сессий
   ```

## 🔑 Способы авторизации

### Вариант А: Консольный скрипт (CLI)
Идеально подходит для локальной настройки на ПК с браузером.

```bash
python auth.py
```
Скрипт автоматически запустит локальный сервер авторизации, откроет браузер для входа в аккаунт Google и сохранит `token.json` в корневую папку.

---

### Вариант Б: Веб-интерфейс (Удаленная авторизация)
Используйте этот вариант, если нужно предоставить доступ другому человеку (например, партнеру) удаленно.

#### 1. Запуск веб-сервера:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

#### 2. Создание публичного туннеля (Cloudflare Tunnel):
Если сервер запущен на удаленной машине или локальном ПК за NAT, воспользуйтесь Cloudflare Tunnel для временного публичного доступа:

```bash
./cloudflared-linux-amd64 tunnel --url http://localhost:8000
```
Скопируйте полученную ссылку вида `https://xxxx-xxxx-xxxx.trycloudflare.com`.

> [!IMPORTANT]
> Не забудьте добавить адрес `https://xxxx-xxxx-xxxx.trycloudflare.com/callback` в список **Authorized redirect URIs** вашего OAuth-клиента в Google Cloud Console, иначе Google вернет ошибку `redirect_uri_mismatch`.

#### 3. Прохождение авторизации:
- Перешлите сгенерированную ссылку пользователю.
- Пользователь перейдет на красивую страницу, нажмет кнопку **«Подключить задачи»** и подтвердит доступ.
- После успешного входа в корневой директории вашего сервера появится файл `token.json`.

---

## 🔒 Безопасность

- Никогда не выкладывайте файлы `credentials.json` и `token.json` в публичный доступ.
- В проекте настроен `.gitignore`, который автоматически защищает эти файлы от случайного коммита.
- Если вы разворачиваете веб-интерфейс в публичном доступе, рекомендуется отключать его сразу после завершения процесса авторизации, чтобы избежать несанкционированного доступа.
